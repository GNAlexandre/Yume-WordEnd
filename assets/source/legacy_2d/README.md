# Planches 2D conservées

Les 11 PNG d’origine sont conservés sans modification ni recompression. Ils ont été générés avec `image_gen` à partir des scans fournis ; aucun scan officiel n’est inclus ici. Le manifeste contient les dimensions, SHA-256, noms identifiés et limites de chaque essai. Tous sont RGBA avec une vraie transparence. Ces planches ne sont pas des atlas d’animation validés : certaines poses ou armes débordent, quelques silhouettes sont coupées.
